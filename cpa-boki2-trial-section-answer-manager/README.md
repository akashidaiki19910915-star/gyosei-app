# CPA日商簿記2級 試験対策編 解答・復習管理アプリ

CPAラーニングの「いちばんわかる日商簿記2級 商業簿記の問題集」「いちばんわかる日商簿記2級 工業簿記の問題集」の試験対策編を、問題ID単位で答案入力・自己採点・履歴保存・復習管理するための個人学習用Webアプリです。

## 重要な注意

このアプリは自動採点ではありません。問題文・解答・解説はアプリ内に保存しません。紙教材・PDF・CPA画面を見ながら答案を入力し、解答解説を見ながら自己採点してください。

本リポジトリには以下を収録していません。

- 教材の問題文
- 教材の解答
- 教材の解説
- CPAロゴ
- 教材画像
- 日本商工会議所の問題文・サンプル問題

アプリ内にあるのは、問題ID、論点名、テンプレート名、答案入力欄、自己採点欄、履歴・復習管理機能のみです。

## 対象問題ID

商業簿記：第1問対策1-1〜1-5、第2問対策2-1〜2-6、第3問対策3-1〜3-3。

工業簿記：第4問対策4-1〜4-4、第5問対策5-1〜5-3。

## 主な機能

- 全問題ID選択
- 問題IDごとの初期テンプレート切替
- 仕訳テーブル、汎用数値入力、株主資本等変動計算書、連結会計、勘定記入、財務諸表・精算表、工程別、部門別、標準原価、CVP、全部原価・直接原価、完全自由テーブル
- 行追加
- 列追加
- 列名変更
- 行別採点（未採点・○・△・×）
- 行別得点入力
- 行別得点合計を問題得点へ反映
- A/B/C判定と次回復習日
- ミス原因管理
- 下書きメモ・復習メモ
- IndexedDB保存
- 履歴復元
- CSV出力
- JSONバックアップ・復元
- 90分タイマー
- 印刷

## ローカル起動方法

```bash
cd cpa-boki2-trial-section-answer-manager
npm install
npm run dev
```

表示されたローカルURLをブラウザで開きます。

## ビルド方法

```bash
npm run build
```

`dist/` が生成されます。

## GitHub Pages公開方法

Vite設定は `base: './'` にしています。GitHub Pagesへ公開する場合は、対象リポジトリのPages設定またはGitHub Actionsで `dist/` を公開してください。

Vite公式ドキュメントでも、`npm run build` により `dist` へ静的成果物を生成し、その `dist` をデプロイする流れが案内されています。

## 動作確認方法

1. 商業 第1問対策1-1を選択し、仕訳テーブルが30行表示されることを確認
2. 設問番号1〜10を入力できることを確認
3. 同じ設問番号を複数行に入れて複合仕訳として扱えることを確認
4. 商業 第2問対策2-2を選択し、連結会計テンプレートが開くことを確認
5. 商業 第3問対策3-2を選択し、財務諸表・精算表テンプレートが開くことを確認
6. 工業 第4問対策4-2を選択し、工程別総合原価計算テンプレートが開くことを確認
7. 工業 第5問対策5-2を選択し、CVP分析テンプレートが開くことを確認
8. 完全自由テーブルを選択し、列追加・列名変更・保存復元を確認
9. 行別採点と行別得点入力後、「行別得点合計を問題得点へ反映」を確認
10. 採点確定して履歴追加し、履歴から復元できることを確認
11. CSV出力、JSONバックアップ、JSON復元を確認
12. 問題文・解答・解説・CPAロゴ・教材画像が収録されていないことを確認

## 保存方式

答案・履歴はIndexedDBに保存します。設定などの軽量データ以外ではlocalStorageに依存しません。
